# Activation Metrics

This subdirectory contains analyses and documentation for metrics tracking the new user activation funnel.

## Purpose

Activation measures whether new users reach the point where they experience meaningful product value. This is the critical bridge between acquisition and retention; users who do not activate rarely retain.

## What Goes Here

- Activation funnel analyses showing conversion at each step
- Time-to-activation distribution analyses
- Activation rate breakdowns by cohort, channel, and segment
- Activation milestone definitions and validation studies
- Impact analyses of onboarding changes on activation rates
- Drop-off analyses identifying where and why users fail to activate

## Conventions

- Name files with the analysis focus and date: `activation-funnel-breakdown-feb-2026.md`
- Always specify which activation definition is being used (reference the glossary)
- Track both the rate and the time-to-activate as complementary metrics
- Compare activation across segments to identify groups needing targeted intervention
- Link activation analyses to relevant experiments in the experiment registry
