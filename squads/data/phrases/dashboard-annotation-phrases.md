# Dashboard Annotation Phrases

## Purpose

Ready-to-use phrases for annotating dashboards. These are designed to be concise, contextual, and self-explanatory for anyone viewing the dashboard without additional context.

## Explaining Spikes

- "Spike on [date]: [campaign name] launched. Expected to normalize by [date]."
- "Elevated on [date]: seasonal effect ([holiday/event]). Compare to same period last year."
- "Peak on [date]: one-time data backfill included. Underlying trend unchanged."
- "Surge [date range]: viral content drove organic traffic. Not sustained."
- "Spike reflects a batch import of [X] accounts on [date]. Not organic growth."
- "High point on [date]: pricing promotion active. Baseline returned [date]."

## Explaining Drops

- "Drop on [date]: tracking outage from [time] to [time]. Data gap, not a real decline."
- "Decline starting [date]: attributed to [product change / market shift / seasonal pattern]."
- "Low on [date]: public holiday in [region]. Expected dip, consistent with prior years."
- "Dip on [date]: pipeline delay. Numbers will backfill within [X] hours."
- "Sharp decline on [date]: [incident description]. Resolution deployed [date]."
- "Drop in [segment] only. Other segments unaffected. Investigation in progress."

## Providing Trend Context

- "Upward trend since [date]: driven by [initiative/feature launch]."
- "Gradual decline over [X] weeks: under investigation. See [link] for latest analysis."
- "Flat trajectory is expected; this metric is seasonally stable in [period]."
- "Trend reversal on [date] coincides with [product/pricing/market change]."
- "Growth rate has decelerated from [X]% to [Y]% per week. Approaching saturation in [segment]."

## Marking Targets and Thresholds

- "Target: [value] (annual plan). Currently [on track / X% behind / X% ahead]."
- "Red line: alert threshold at [value]. Triggers investigation if crossed for [X] consecutive days."
- "Industry benchmark: [value]. Source: [benchmark source, year]."
- "Internal SLA: [value]. Current performance: [value]."
- "Historical average for this period: [value]."

## Data Quality Notices

- "Data delayed by [X] hours as of [timestamp]. Refresh in progress."
- "Numbers for [date range] are preliminary and may be revised."
- "Metric definition changed on [date]. Values before this date use the prior formula."
- "Segment '[name]' was added on [date]. No historical data available before this point."
- "Source system migration on [date]. Minor discrepancies possible in [date range]."
- "This chart excludes [test accounts / internal users / specific segment] by design."

## Methodology Notes

- "Calculated as [formula]. See metric dictionary for full definition."
- "7-day rolling average applied to smooth daily volatility."
- "Cohort-based: each line represents users who signed up in the labeled month."
- "Year-over-year comparison adjusted for [leap year / calendar alignment]."
- "Percentages are of the filtered population shown, not of all users."
