# Task: Onboard New Analyst
> Agent(s): Data Team Lead, Buddy Analyst
> Frameworks: Onboarding Framework, 30-60-90 Day Plan
> Checklists: new-analyst-onboarding-checklist, access-provisioning-checklist
> Template: onboarding-plan-template
> Registry: task-log

## Objective
Onboard a new data analyst or data scientist onto the data team with a structured program
that gets them productive within 30 days, fully ramped within 90 days, and deeply integrated
into team processes and culture.

## Prerequisites
- New team member has accepted the offer and start date is confirmed.
- Manager has prepared the onboarding plan.
- Buddy analyst is assigned.
- Access request forms are ready for submission.

## Steps
1. **Pre-start preparation (before Day 1)** -- Set up before the new hire arrives:
   - Provision accounts: data warehouse, BI platform, analytics tools, code repository.
   - Set up development environment with required packages and configurations.
   - Create accounts in project management tools, Slack, and documentation platforms.
   - Prepare a welcome document with team overview, key contacts, and first-week schedule.
2. **Day 1: Welcome and orientation** --
   - Welcome meeting with the team lead. Share team mission, values, and goals.
   - Introduce to the buddy analyst (their primary resource for questions).
   - Walk through the team structure and each member's focus area.
   - Verify all access is working (warehouse, BI, analytics platforms).
   - Share the 30-60-90 day plan.
3. **Week 1: Learn the landscape** --
   - Read the metric registry. Understand the KPI tree and North Star Metric.
   - Read the event taxonomy and understand data collection.
   - Explore the data warehouse: key tables, schemas, and naming conventions.
   - Review 3-5 recent analysis reports to understand quality standards.
   - Attend all recurring team meetings as an observer.
4. **Week 2: Hands-on learning** --
   - Complete a guided analysis exercise: replicate a past analysis from scratch.
   - Write first SQL queries against the data warehouse.
   - Build a simple dashboard in the BI platform.
   - Review the data quality process and run a data quality check on one table.
   - Shadow the buddy on a real analysis task.
5. **Weeks 3-4: First real contribution** --
   - Take on a small, well-scoped analysis request (pre-selected by manager).
   - Complete the analysis with support from the buddy.
   - Present findings to the team in a low-stakes format.
   - Receive feedback on methodology, communication, and tooling.
   - Start attending cross-squad sync meetings.
6. **Days 31-60: Build independence** --
   - Take on progressively larger analysis tasks independently.
   - Contribute to the weekly data digest or exec report.
   - Run a data quality review on assigned metrics.
   - Start building relationships with stakeholders in assigned squad(s).
   - Contribute to the metric registry (define or refine a metric).
7. **Days 61-90: Full ramp** --
   - Own a complete analysis end-to-end: scoping, execution, presentation.
   - Support or lead an experiment analysis.
   - Present findings at a cross-functional meeting.
   - Identify and propose an improvement to a process or tool.
   - Complete any required training or certifications.
8. **Set up 1:1 cadence** -- Establish regular check-ins:
   - Daily check-in with buddy (first 2 weeks, then weekly).
   - Weekly 1:1 with manager (ongoing).
   - Bi-weekly 1:1 with buddy (weeks 3-12).
9. **Create a learning plan** -- Identify skill gaps and development areas:
   - SQL proficiency assessment.
   - Statistical methods knowledge.
   - BI platform expertise.
   - Domain knowledge (product, business model).
   Create a learning plan with resources and milestones.
10. **30-day check-in** -- At the 30-day mark:
    - Review progress against the 30-day goals.
    - Gather feedback from the buddy and manager.
    - Identify any blockers or concerns.
    - Adjust the 60-90 day plan if needed.
11. **60-day check-in** -- At the 60-day mark:
    - Review progress against 60-day goals.
    - Assess independence level.
    - Discuss longer-term development goals.
    - Plan the 90-day milestone project.
12. **90-day review** -- At the 90-day mark:
    - Formal review of onboarding success.
    - Celebrate achievements.
    - Transition from onboarding to regular performance management.
    - Document lessons learned for improving the onboarding process.

## Deliverable
An onboarding program for the new analyst consisting of:
- 30-60-90 day plan with specific milestones.
- Access provisioning checklist (completed).
- Learning plan with resources.
- Buddy assignment and check-in schedule.
- 30-day, 60-day, and 90-day review documents.

## Quality Gate
- [ ] All accounts and access are provisioned before Day 1.
- [ ] Buddy analyst is assigned and briefed.
- [ ] 30-60-90 day plan is documented and shared with the new hire.
- [ ] New hire completes a guided analysis by end of Week 2.
- [ ] New hire presents a first real analysis by end of Week 4.
- [ ] 30-day check-in is conducted with documented feedback.
- [ ] 60-day check-in is conducted with independence assessment.
- [ ] 90-day review is completed with transition to regular management.
