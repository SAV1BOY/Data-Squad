# Executive Dashboards

This subdirectory contains specifications and documentation for executive-level dashboards used by leadership and the board.

## Purpose

Executive dashboards provide the highest-level view of business health. They must be accurate, clear, and free of clutter. This directory ensures these dashboards are well-documented, consistently maintained, and aligned with leadership's information needs.

## What Goes Here

- Dashboard specifications for each executive dashboard
- Metric selection rationale explaining why each metric was included
- Layout and design documentation
- Board reporting versions and presentation-ready exports
- Change logs recording all modifications
- Stakeholder feedback and requested adjustments

## Conventions

- Name files after the dashboard: `exec-overview-spec.md`
- Executive dashboards should contain no more than 8-10 metrics to maintain focus
- Every metric shown must have a clear definition accessible via drill-down or tooltip
- Review executive dashboards monthly with the data chief to ensure continued relevance
- Any metric change on an executive dashboard requires data-chief approval
- Keep a change log so leadership understands when and why the dashboard evolved
