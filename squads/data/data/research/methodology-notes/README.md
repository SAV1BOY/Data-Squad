# Methodology Notes

This subdirectory contains internal documentation of the statistical methods, analytical frameworks, and technical approaches used by the data team.

## Purpose

Documenting methodology ensures analytical consistency, enables peer review, and helps new team members understand how and why specific approaches were chosen. It serves as the team's analytical playbook.

## What Goes Here

- Statistical methodology documentation (e.g., how we compute confidence intervals for experiments)
- Sampling strategy descriptions and justifications
- Causal inference approaches used in observational analyses
- Data transformation and normalization methods
- Model evaluation frameworks and criteria
- Best practices and style guides for SQL, Python, and notebook-based analyses
- Technical notes on edge cases encountered and how they were handled

## Conventions

- Name files descriptively: `experiment-sample-size-calculation-method.md`
- Include worked examples where possible to make methods concrete
- Reference external sources (papers, textbooks, blog posts) that informed the approach
- Version methodology documents when approaches change; keep old versions for reference
- Review methodology notes annually to ensure they reflect current best practices
- When a methodology note contradicts common industry practice, explain the reasoning
