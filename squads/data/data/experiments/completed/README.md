# Completed Experiments

This subdirectory contains the final analysis and results for experiments that have concluded.

## Purpose

Completed experiment documentation is the team's institutional memory for what has been tried, what worked, and what did not. Every completed experiment, regardless of outcome, contributes to the team's understanding and prevents repeating past mistakes.

## What Goes Here

- Final analysis reports with statistical results, confidence intervals, and effect sizes
- Decision documentation (ship, kill, iterate) with rationale
- Lessons learned and unexpected findings
- Follow-up recommendations and links to any subsequent experiments
- Raw result summaries suitable for sharing with stakeholders

## Conventions

- Name files with the experiment ID: `EXP-001-onboarding-simplification.md`
- Every completed experiment must have a write-up, even if the result was inconclusive
- Include the final sample size, test duration, and statistical significance
- Document both the primary metric result and any notable secondary metric findings
- Update the experiment registry with the summary result and decision
- Tag the document with relevant metric categories for cross-referencing
