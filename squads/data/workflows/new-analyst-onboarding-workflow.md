# New Analyst Onboarding Workflow

## Purpose
Bring a new analyst from day-one orientation to independent contribution within 30 days through structured tool setup, context immersion, guided first tasks, feedback loops, and progressive independence.

## Trigger
- New analyst joins the Data Squad
- Internal transfer to the Data Squad from another team
- Returning analyst after extended absence (> 3 months)

## Agents Involved
- **Analytics Architect**: Provides technical onboarding and tool access
- **Insight Narrator**: Provides context, culture, and communication standards
- **Retention Strategist**: Assigns first tasks and provides strategic context
- **Data Quality Sentinel**: Introduces quality standards and review processes

## Steps

### Phase 1: Tools and Access (Days 1-3)
1. **Analytics Architect** provisions all tool access: data warehouse, BI tool, experimentation platform, version control, and communication channels.
2. **Analytics Architect** walks the new analyst through the technical stack: which tool for which purpose, how to connect, and where to find documentation.
3. **Analytics Architect** ensures the analyst can run a basic query against the warehouse and produce a simple chart in the BI tool.
4. **Analytics Architect** provides access to the squad repository and explains the folder structure: workflows, docs, registries.
5. **Analytics Architect** assigns a "technical buddy" who the analyst can ask tool questions to without hesitation.

### Phase 2: Context Immersion (Days 4-7)
6. **Insight Narrator** walks the analyst through the squad overview: vision, philosophy, what the squad does and does not do.
7. **Insight Narrator** introduces the agent roles: which agents exist, what each does, and how they collaborate.
8. **Retention Strategist** provides strategic context: current North Star metric, quarterly priorities, key experiments in progress.
9. **Insight Narrator** assigns required reading: getting-started guide, operating system, naming conventions, dashboard philosophy.
10. **Data Quality Sentinel** introduces the quality standards: the RalphLoop quality gates, data quality SLAs, and validation expectations.
11. **Insight Narrator** schedules the analyst to shadow 2-3 existing workflows in progress to observe how the squad operates.

### Phase 3: First Task (Days 8-14)
12. **Retention Strategist** assigns the first task: a well-scoped, low-stakes analysis with a clear question, known data sources, and an expected output format.
13. **Analytics Architect** provides the analyst with starter queries and points them to relevant data models.
14. The analyst executes the task independently, with the technical buddy available for questions.
15. **Data Quality Sentinel** reviews the analyst's work through a lightweight version of the quality gates: data integrity, validation, and clarity.
16. **Insight Narrator** provides feedback on communication quality: is the output understandable, well-structured, and actionable?

### Phase 4: Feedback and Calibration (Days 15-21)
17. **Retention Strategist** holds a 1:1 debrief on the first task: what went well, what was confusing, what took longer than expected.
18. **Retention Strategist** assigns a second task with slightly broader scope: more ambiguity, requires choosing the analytical approach.
19. The analyst completes the second task and presents the findings to the squad in a 15-minute walkthrough.
20. All agents provide constructive feedback on methodology, communication, and quality.
21. **Insight Narrator** collects the analyst's feedback on the onboarding process itself: what was helpful, what was missing.

### Phase 5: Independence (Days 22-30)
22. **Retention Strategist** assigns the analyst to a real workflow as a contributing team member (not just observer).
23. The analyst participates in the weekly squad sync and contributes to at least one discussion.
24. **Analytics Architect** removes the "new analyst" scaffolding: the analyst now uses standard review processes instead of extra hand-holding.
25. **Retention Strategist** sets 30-60-90 day goals with the analyst: what independence looks like at each milestone.
26. **Insight Narrator** updates the onboarding guide based on the analyst's feedback for the next hire.

## Inputs
- New analyst profile: background, technical skills, previous experience
- Tool provisioning checklist
- Squad documentation (getting-started guide, operating system, etc.)
- Current squad priorities and available starter tasks

## Outputs
- Fully provisioned analyst with tool access
- Completed first and second analysis tasks with feedback
- 30-60-90 day goal document
- Updated onboarding guide incorporating feedback

## Quality Gates

| Gate | Criteria | Owner |
|------|----------|-------|
| G1: Tools Working | Analyst can query the warehouse and produce a chart independently | Analytics Architect |
| G2: Context Absorbed | Analyst can articulate the North Star metric, squad priorities, and quality standards | Insight Narrator |
| G3: First Task Complete | First task passes lightweight quality review within 7 days of assignment | Data Quality Sentinel |
| G4: Feedback Incorporated | Second task shows improvement based on first task feedback | Retention Strategist |
| G5: Independence Achieved | Analyst contributes to a real workflow without additional scaffolding by day 30 | Retention Strategist |

## Registry Updates
- **Team Registry**: Add new analyst with start date, role, buddy assignment, and onboarding status.
- **Access Log**: Document all tool access granted with dates and approvers.
- **Onboarding Backlog**: Record feedback for continuous improvement of the onboarding process.
- **Knowledge Base**: Add any new documentation or FAQ entries that emerged from the analyst's questions.

## Onboarding Timeline Summary
| Week | Focus | Key Milestone |
|------|-------|---------------|
| Week 1 | Tools + Context | Can query data and articulate squad mission |
| Week 2 | First Task | Completes scoped analysis with quality review |
| Week 3 | Feedback + Second Task | Presents findings, incorporates feedback |
| Week 4 | Real Workflow | Contributing to production work independently |
