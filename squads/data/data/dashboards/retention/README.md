# Retention Dashboards

This subdirectory contains specifications and documentation for retention and engagement dashboards.

## Purpose

Retention dashboards help the product team monitor cohort health, identify engagement patterns, and detect early warning signs of churn. This directory holds the blueprints for these critical monitoring tools.

## What Goes Here

- Dashboard specifications for retention-focused dashboards
- Cohort retention heatmap configurations
- Engagement depth visualization documentation
- Churn early-warning dashboard specifications
- Segment-level retention comparison dashboard documentation
- Change logs and enhancement requests

## Conventions

- Name files after the dashboard: `retention-overview-spec.md`
- Retention dashboards should default to cohort week as the time grain (DEC-005)
- Include both visual retention curves and tabular data for precision
- Support filtering by segment, plan tier, and acquisition channel
- Ensure dashboards clearly indicate the data freshness timestamp
- Review with the retention lead monthly to align with current focus areas
