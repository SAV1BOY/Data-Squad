# Referral Metrics

This subdirectory contains analyses and documentation for referral program metrics and viral growth tracking.

## Purpose

Referral metrics measure how effectively existing users bring new users to the product. A healthy referral loop is a cost-effective acquisition channel and a signal of strong user satisfaction.

## What Goes Here

- Referral program performance reports (invites sent, accepted, activated)
- Viral coefficient calculations and trend tracking
- Referral quality analyses comparing referred users to other acquisition channels
- Referral program experiment results and optimization findings
- Network effect analyses if applicable
- Referrer behavior studies (who refers, when, and why)

## Conventions

- Name files with the analysis type and date: `referral-program-q1-2026-review.md`
- Track the full referral funnel: invite sent, invite opened, signup, activation
- Compare referred user retention and CLV against other channels
- Segment referral behavior by user type (power users, plan tier, tenure)
- Document any referral program changes alongside their metric impact
