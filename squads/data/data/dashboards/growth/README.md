# Growth Dashboards

This subdirectory contains specifications and documentation for growth and acquisition dashboards.

## Purpose

Growth dashboards serve the growth squad with real-time and periodic views of acquisition funnels, channel performance, and activation metrics. This directory holds the specifications that define what each dashboard shows and why.

## What Goes Here

- Dashboard specifications for growth-related dashboards
- Acquisition funnel visualizations and filter configurations
- Channel comparison dashboard documentation
- Activation tracking dashboard specifications
- A/B test monitoring dashboard configurations
- Change logs and improvement requests

## Conventions

- Name files after the dashboard: `growth-overview-spec.md`
- Growth dashboards should support filtering by channel, cohort, and time period
- Include both volume and quality metrics side by side
- Ensure experiment monitoring views do not enable premature decision-making
- Review with the growth lead bi-weekly to ensure dashboards match current priorities
- Document any custom SQL or calculated fields used in dashboard panels
