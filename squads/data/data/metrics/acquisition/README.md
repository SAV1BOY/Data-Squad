# Acquisition Metrics

This subdirectory contains analyses and documentation for metrics related to new user acquisition and channel performance.

## Purpose

Acquisition metrics measure how effectively the product attracts new users across different channels. This directory tracks acquisition volume, quality, cost, and channel mix over time.

## What Goes Here

- Acquisition funnel analyses (impression to signup to activation)
- Channel performance reports comparing organic, paid, referral, and partnership sources
- Acquisition cost analyses (CAC by channel and segment)
- Signup volume trend reports and anomaly investigations
- Attribution methodology documentation and accuracy assessments
- Seasonal pattern analyses for acquisition

## Conventions

- Name files with the analysis type and period: `channel-performance-q1-2026.md`
- Always pair volume metrics with quality metrics (e.g., signups and activation rate by channel)
- Distinguish between vanity acquisition metrics and those tied to downstream value
- Update channel performance reports monthly at minimum
- Flag any attribution methodology changes that would affect historical comparisons
