# Experiment Backlog

This subdirectory contains experiment ideas and proposals that have not yet started.

## Purpose

The backlog is the pipeline of future experiments. Storing proposals here ensures good ideas are not lost, allows prioritization discussions, and provides a structured place to develop experiment designs before launch.

## What Goes Here

- Experiment proposals with initial hypothesis and motivation
- Rough designs specifying the metric, audience, and expected effect size
- Priority assessments and sequencing recommendations
- Research or data that supports the hypothesis
- Feedback from reviewers on the experiment design

## Conventions

- Name files with the experiment ID if assigned: `EXP-003-pricing-page-redesign.md`
- Include at minimum: hypothesis, primary metric, target segment, and estimated duration
- Indicate the priority level and any dependencies on other work
- Move the file to `running/` when the experiment launches
- Review the backlog monthly to reprioritize and prune stale proposals
- Proposals older than 6 months without action should be reconsidered or archived
